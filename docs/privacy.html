KTR_LyricMV

プライバシーポリシー

制定日: 2026年10月13日

このページは、歌詞動画を作る Windows 用ソフト KTR_LyricMV（以下「本ソフト」）が、利用者の情報をどう扱うかを説明します。Microsoft Store 版・インストーラー版・zip 版のどれにも当てはまります。

集める情報

本ソフトは、利用者の個人情報を集めません。名前・メールアドレス・アカウント・位置・使い方の記録などを、作者やほかの誰かに送ることはありません。広告も、利用状況の送信（テレメトリ）もありません。

インターネットとの通信

本ソフトはインターネットに接続しません。

  • 文章の読み上げで VOICEVOX を使うときだけ、同じパソコンの中で動いている VOICEVOX（127.0.0.1）と通信します。パソコンの外には出ません。
  • JIZURA レイヤーは Microsoft Edge WebView2 の中で動きますが、ネットワークへの通信はすべて止めています。
  • 動画の書き出しでは、利用者が入れた ffmpeg を同じパソコンの中で動かします。

パソコンに保存する情報

本ソフトは、次のものを利用者のパソコンの中にだけ保存します。

  • 設定・プリセット・テンプレート・最近使ったファイルの一覧・エラーの記録（%APPDATA%\KTR_LyricMV）
  • 作り直せる一時ファイル（%TEMP%\KTR_LyricMV など）
  • 利用者が保存したプロジェクトや書き出した動画（利用者が選んだ場所）

これらは外に送られません。エラーの記録も、パソコンの中に残すだけです。不要になったら、上のフォルダを削除できます。

Microsoft Store について

Microsoft Store から入手した場合、入手やアプリの異常終了などについて Microsoft が集める情報は、Microsoft のプライバシーに関する声明に従って扱われます。作者が Microsoft から受け取るのは、個人を特定できない集計（入手数など）と、Microsoft が提供する異常終了の報告だけです。

このポリシーの変更

内容を変えるときは、このページを更新し、制定日の下に更新日を書きます。

Privacy policy (English)

Effective: October 13, 2026

  • KTR_LyricMV does not collect any personal information. It sends no data to the author or anyone else, and has no ads, accounts or telemetry.
  • It does not connect to the internet. It talks only to the VOICEVOX engine on the same PC (127.0.0.1) when the user uses the read-aloud feature. Its WebView2 component has all network access blocked. ffmpeg, installed by the user, runs on the same PC.
  • Settings, presets, recent-file lists and error logs are stored only on the user's PC (%APPDATA%\KTR_LyricMV); temporary files in %TEMP%\KTR_LyricMV; projects and videos where the user saves them. None of it is sent anywhere.
  • If obtained from the Microsoft Store, data Microsoft collects is handled under the Microsoft Privacy Statement. The author receives only aggregated, non-identifying figures and the crash reports Microsoft provides.
  • Contact: KTR music lab. (KTR_Shibata), via GitHub Issues.
